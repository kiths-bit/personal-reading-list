# Personal Reading List

A simple React reading list application that allows users to search for books, add books to a personal reading list, and remove them when they are no longer needed.

The application uses the Open Library API for book search results and browser localStorage to persist the user's reading list.

## Features

- Search for books using the Open Library API
- Display book title, author, publication year, and cover image
- Add books to a personal reading list
- Remove books from the reading list
- Persist the reading list using browser localStorage
- Clear empty state for a new user
- Loading state while fetching book data
- Error state when book data cannot be loaded
- Reviewer controls for demonstrating loading, error, and empty states
- Responsive layout for smaller screens
- Keyboard-accessible form controls and buttons

## Tech Stack

- React
- Vite
- JavaScript
- CSS
- Open Library Search API
- Browser localStorage
